This simulation consists of three separate real railways and timetables with increasing levels of difficulty as follows: North Pennine Services - fairly easy; South and Central Pennine Services - moderately difficult; and Combined Pennine Services - difficult.  A set of notes is available in the Documentation folder containing operational hints and a brief history of each of the lines.

Signals should be on the left hand side of the track as is current practice in the UK.
